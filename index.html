LLM Playground

A small workbench for model parameters

This page sends prompts to the provider you configure. It does not ship with a key, a proxy, or a server. Everything is one HTML file and your browser.

01

Pick a provider and paste a key

Open Parameters, choose a provider, and paste a key into the API key field. There is no model to choose: the page asks the provider which model the key can use. A base URL in Advanced points at any OpenAI-compatible endpoint.

02

Set temperature and length

The sampling card is one control. Drag the ruler, tap a preset, or type into the temperature figure. Max output tokens is in the same card. Both values travel with the next request.

03

Send and compare

Press Enter to send and Shift + Enter for a new line. Stop a reply while it streams, retry the last one, copy a response, or export the session as JSON. Rename a session with the pencil next to it, or double-click its title; Enter saves, Esc cancels.

About keys and browser requests

Your key is kept in session storage, or in local storage only when you tick Remember on this device. It is never placed in the page source or in exported files. The page asks your provider for an available model and falls back to a known default if the provider does not expose a list. Some providers block direct browser calls through CORS; if a request fails before reaching the provider, try OpenRouter or a proxy you control. Gemini and Anthropic keys are sent from this page as documented by those providers.
